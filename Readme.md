# 👋 About Me

Hi, I'm Amir Furquani! 👋

I'm an AI/ML Engineer and Software Developer focused on building intelligent, data-driven applications and scalable software solutions. My work lies at the intersection of Machine Learning, Deep Learning, Computer Vision, and Software Engineering, with an emphasis on translating complex technical concepts into practical, real-world applications.

I have hands-on experience designing and developing end-to-end AI systems, including data preprocessing, exploratory data analysis, feature engineering, model development, evaluation, optimization, and deployment. My experience spans industrial defect detection, medical image analysis, predictive analytics, and applied machine learning, alongside exploring Generative AI, Large Language Models (LLMs), and Retrieval-Augmented Generation (RAG).

Beyond AI/ML, I have a strong foundation in Data Structures and Algorithms, Object-Oriented Programming, Database Management Systems, and software development principles. I enjoy solving challenging engineering problems, writing efficient and maintainable code, and building applications that combine intelligent models with reliable software architectures.
